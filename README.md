# Дино 3D

Трёхмерный ремейк раннера с динозавриком (Chrome Dino) на three.js.
Строго монохромная графика: чёрный, белый и оттенки серого. Без текстур.

## Игра

- Низкополигональный T-Rex, камера сбоку, бесконечный раннер.
- Прыжок: **Пробел / W / ↑**, приседание: **↓ / S**, пауза: **P**, заново: **R**.
- Препятствия: кактусы трёх размеров (в том числе группами) и птеродактили
  на двух высотах — низких надо перепрыгивать или приседать под ними, под
  высокими достаточно пробежать.
- Очки и рекорд (localStorage), оверлей «Игра окончена» с кнопкой «Начать заново».
- Скорость нарастает со временем.

## Тесты

- FPS, время кадра, draw calls, треугольники, график времени кадра.
- Информация о WebGL2 и ключевых расширениях.
- Бенчмарк: по N секунд на каждый уровень качества (Низкое / Среднее / Высокое),
  таблица и столбчатая диаграмма среднего FPS.
- Быстрая проверка сцены: WebGL, наличие рендера, монохром палитры, localStorage.

## Запуск

Статический сайт, всё лежит рядом. three.js — в \`vendor/\`.

\`\`\`
python3 -m http.server 8080
\`\`\`

Открыть http://localhost:8080/
